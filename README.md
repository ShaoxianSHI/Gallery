# Gallery

本地优先的 macOS 相册：**照片留在你自己的文件夹里，软件只是它的一个视图。**

指定一个本地文件夹作为「库」，Gallery 只读不接管。照片与视频始终是普通文件，
卸载 Gallery 也不会影响它们。

## 功能

- **浏览**：实时跟随磁盘变化；全部照片、相册、日历三种方式，照片与视频同列。
- **查找**：搜索全库、筛选当前层；按时间 / 相机 / 镜头 / 地点 / 关键词分组排序，可放映。
- **元数据**：读写 EXIF / IPTC / XMP；拍摄时间与位置可写回，其余只读。
- **事件与导入**：把照片归入旅行、演出或影片，可设封面；事件只存在 Gallery 自己的库里。
- **数据安全**：扫描、索引与预览只读；写操作由你亲手触发并留日志，除粘贴与新建相册外均可
  `⌘Z` 撤销。

## 安装

需要 macOS 13 或更高版本。Python 与依赖由 [uv](https://docs.astral.sh/uv/) 管理；
[exiftool](https://exiftool.org/) 可选，读写 IPTC / XMP 与写回元数据时需要。

```bash
brew install uv exiftool
git clone https://github.com/ShaoxianSHI/Gallery.git
cd Gallery
uv sync
uv run gallery
```

打开指定文件夹，或打包成 `.app`：

```bash
uv run gallery ~/照片

uv sync --group build
uv run --group build python scripts/build_app.py   # 产物 dist/Gallery.app
```

## 使用

启动后按 `⌘O` 选一个文件夹作为库。

### 快捷键

|------|--------|
| 打开大图 / 播放视频 | 双击、`回车` |
| 返回网格 / 取消选中 | `Esc` |
| 上一张 / 下一张 | `←` / `→` |
| 播放 / 暂停视频 | `空格`，或点一下画面 |
| 适应窗口 / 实际大小 / 缩放 | `⌘0` / `⌘1` / `⌘+`、`⌘-` |
| 放大 / 缩小缩略图 | `⌃⇧↑` / `⌃⇧↓` |
| 搜索 | `⌘F` |
| 搜索 ⇄ 筛选当前视图 | 搜索框右侧的双向箭头 |
| 撤掉最后一条筛选条件 | `⇧Esc` |
| 重命名 / 刷新当前层 | `⌘R`（选中一格 / 未选中） |
| 移到废纸篓 | `⌘⌫` |
| 编辑拍摄时间与位置 | `⇧⌘I` |
| 撤销上一次写操作 | `⌘Z` |
| 默认应用打开 / 访达显示 | `⇧⏎` / `⌘⏎` |
| 打开照片所属影片的网站 | `⌥` 点照片 |

| 铺满窗口 / 关闭窗口 / 退出 | `⌃⌘F` / `⌘W` / `⌘Q` |

### 浏览

- **全部照片**整库平铺；**相册**一个子文件夹一个，双击进入，右键可设封面。
- **日历**按拍摄时间分层：`Y` / `M` / `W` 切年 / 月 / 周，`←` / `→` 翻页，`T` 回今天。
- **分组**：「显示 → 分组」里切换卡片式（每组一张卡片）与分区式（连续铺开 + 组标题）。
- 按名称排序时中文按拼音。
- **刷新**（`⌘R`，未选中任何一格）：重扫当前层，文件变化漏检时用它。
- **放映**：右上角三角按钮，按网格顺序播放，默认 3 秒一张；`空格` 暂停，`Esc` 回网格。
- **大图页底部的画廊条**：按当前层的顺序摆出前后的照片，当前那张居中；点一格就换到那一张。
  「显示 → 显示画廊」可以关掉。

### 搜索与筛选

- 语法相同：`#相机 Canon`、`#ISO >800`、`#拍摄时间 2024-05`；不带 `#` 按文件名。
- **搜索**横跨全库；**筛选**只收窄当前层，条件跟着换层走。
- 条件显示为面包屑右侧的胶囊：点文字修改，点 `✕` 撤掉。

### 外部应用

- 标题条左侧的按钮：左半打开第一项，右半列出全部。
- 大图页是看图软件；视频页是 QuickTime Player 与 IINA（装了才有）。
- 有拍摄位置时多出「地图」「Google 地图」；网格页是当前文件夹（访达、QSpace、终端）。
- 日历页是系统「日历」与 Google 日历。
- 顺序在「设置 → 外部应用顺序…」里调。

### 导入

- **导入影片**：Bilibili、YouTube、抖音、TikTok、爱奇艺、腾讯视频、优酷、芒果TV、JavDB、Pornhub。
- 每行一个编号或链接；网址按域名认来源，裸编号按入口算。
- 封面存进当前文件夹，不覆盖同名文件。
- **从「演迹」导入…**：读 `.xlsx` 演出列表，建成事件。
- 重复导入会先问跳过还是全导。

### 设置

- **应用级**：主题、语言（跟随系统 / 简体中文 / English，改完重启生效）、
  背景（纯色 / 图片 / 生成水墨）、动画速度、放映间隔、外部应用顺序、启动时打开上次的库。
- **库级**：影片网站、缓存上限。
- 另有清除缓存、打开日志文件夹与版本信息；最近打开可在「文件」菜单清空。

## 支持的格式

| 能力 | 格式 |
|------|------|
| 读 + 写（EXIF / IPTC / XMP 都能存） | JPEG、PNG、TIFF |
| 读写，但容器只存 XMP 地名 | HEIC / HEIF、WebP |
| 只能写 XMP 地名 | GIF |
| 只读 | BMP |
| 视频：播放、首帧、只读元数据 | MP4、MOV、M4V、AVI、3GP |
| **尚不支持** | 常见 RAW（CR2/CR3、NEF、ARW、DNG）、MKV、WebM |

## 数据与备份

首次打开库时，Gallery 在库根目录下建一个 `.gallery/`：

```
<库根目录>/
├── 你的照片文件夹/          # Gallery 不做任何整理
└── .gallery/
    ├── config.toml         # 库级配置（相册封面、界面偏好、影片网站、缓存上限）
    ├── index.db            # 索引缓存，可重建
    ├── events.db           # 事件、封面与照片的关联，删掉就没了
    └── journal/            # 写操作日志，用于回溯与撤销
```

- `config.toml`：配置，建议自己留一份副本。
- `index.db`、`journal/`：缓存，删除后重新扫描即可恢复。
- **`events.db` 不是缓存**：删掉无法重建。绑定存的是相对库根的路径，搬库或换机器后仍在；
  备份时请带上。

Gallery 不往照片目录写 `.gallery/` 之外的文件。应用日志在
`~/Library/Application Support/Gallery/logs/gallery.log`，报告问题时请一并附上。

## 已知限制

- 只有拍摄时间（含时区）与位置可以写回；相机、镜头、光圈 / 快门 / ISO 等拍摄事实只读。
- 没装 exiftool 时退回 Pillow 读基础 EXIF，IPTC / XMP 不可用，「编辑元数据」不出现。
- 地点反查使用随包分发的离线城市库，不联网、不上传坐标。
