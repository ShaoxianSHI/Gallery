# Gallery

一个本地优先的 macOS 相册软件：**照片留在你自己的文件夹里，软件只是它的一个视图。**

指定一个本地文件夹作为「库」，Gallery 读取它而不接管它。照片与视频始终是普通文件，用访达、
Photoshop 或任何别的工具都能打开；即使卸载 Gallery，文件与元数据依然完整可读。

## 功能

- **实时浏览**：打开文件夹即可看，磁盘上的增删改立刻反映到界面。三种浏览方式任选：全部照片平铺、
  按子文件夹分相册逐层进入、按拍摄时间分年 / 月 / 周。视频和照片一起出现：网格里是第一帧，
  双击就在应用里播放（进度条可拖动，`⇧⏎` 仍交给系统默认应用）。
- **找照片**：搜索横跨整个库，筛选只收窄当前这一层；可按拍摄时间、相机、镜头、地点、关键词等
  字段分组与排序；也能让当前这一层自动放映。
- **元数据**：读取 EXIF / IPTC / XMP；拍摄时间与位置可以修改，并写回照片文件本身。视频也能看
  拍摄时间、位置、时长与编码（只读，不写回）。
- **事件**：给照片标上「这是哪次旅行 / 那场演出 / 哪部影片」，再按事件挑选、筛选、排序；每个事件
  可以指定一张封面。事件记在 Gallery 自己的库里，不写进照片文件。「演迹」导出的演出列表可直接
  导入，影片还能按番号或链接从十个来源抓取封面与资料。
- **交给别的程序**：用默认看图软件打开、在访达中显示、在系统「日历」与地图里打开对应位置。
- **不碰你的照片**：扫描、索引、预览一律只读。会动文件的只有你亲手触发的几条命令，每一次都留下
  日志、都能 `⌘Z` 撤销（粘贴与新建相册只记日志、不进撤销栈）。

## 安装

需要 macOS 13 或更高版本。Python 版本与依赖都由 [uv](https://docs.astral.sh/uv/) 管理，
不必自己装 Python；[exiftool](https://exiftool.org/) 可选，读 IPTC / XMP 与写回元数据时需要它。

```bash
brew install uv exiftool
git clone https://github.com/ShaoxianSHI/Gallery.git
cd Gallery
uv sync                     # 创建虚拟环境并装好依赖
uv run gallery              # 启动
```

也可以直接打开某个文件夹：

```bash
uv run gallery ~/照片
```

想做成可双击的 `.app`（解释器、依赖与 Qt 一起打包，拷到别的 Mac 上就能运行）：

```bash
uv sync --group build
uv run --group build python scripts/build_app.py
```

产物在 `dist/Gallery.app`。

## 使用

启动后用 `⌘O` 选一个文件夹当库。

| 操作 | 快捷键 |
|------|--------|
| 打开大图 / 播放视频 / 退回网格（已在最外层时取消选中） | 双击、`回车` / `Esc` |
| 上一张 / 下一张 | `←` / `→` |
| 播放 / 暂停视频 | `空格`，或点一下画面 |
| 适应窗口 / 实际大小 / 缩放 | `⌘0` / `⌘1` / `⌘+`、`⌘-` |
| 搜索（文件名、相册、元数据） | `⌘F` |
| 在搜索与「筛选当前视图」之间切换 | 点搜索框右边那枚双向箭头按钮 |
| 撤掉最后一条筛选条件 | `⇧Esc` |
| 重命名（照片或相册） | 网格下再点一次已选中的缩略图，或 `⌘R`（选中一格时） |
| 刷新当前层（重新扫描磁盘、重新分组） | `⌘R`（没有选中任何一格时） |
| 移到废纸篓 | `⌘⌫` |
| 编辑拍摄时间与位置 | `⇧⌘I` |
| 撤销上一次写操作 | `⌘Z` |
| 在默认应用里打开 / 在访达中显示 | `⇧⏎` / `⌘⏎` |
| 打开照片所属影片的网站 | 按住 `⌥` 点那张照片 |
| 拷贝 / 拷贝路径 / 粘贴 / 全选 | `⌘C` / `⇧⌘C` / `⌘V` / `⌘A` |
| 在原位置造一份副本 | `⌘D` |
| 新建相册 | `⇧⌘N` |
| 显示元数据面板 | `⌘I` |
| 铺满窗口 | 双击标题栏，或 `⌃⌘F` |
| 关闭窗口（应用还在）/ 退出 | `⌘W` / `⌘Q` |

- **浏览方式**在「显示 → 浏览方式」里：**全部照片**把整库平铺在一起；**相册**是一个子文件夹一个
  相册，双击进入，可以给相册指定封面（右键菜单），不指定就用里面第一张照片；**日历**按拍摄时间
  分年 / 月 / 周三层（`Y` / `M` / `W` 切层，`←` / `→` 翻页，`T` 回到今天）。
- **搜索与筛选**用同一套条件语法（`#相机 Canon`、`#ISO >800`、`#拍摄时间 2024-05`，不带 `#`
  就是按文件名），区别只在管到哪儿：**搜索**横跨整个库，一提交整层就被结果接管；**筛选**只收窄
  当前这一层，视图本身不动，条件跟着你换层走。条件会作为胶囊摆在面包屑那一行的右端，点文字是改、
  点 `✕` 是撤掉。
- **分组与排序**在「显示」菜单里。分组有两种形态（子菜单末尾切换）：**卡片式**把每组变成一张可以
  双击进去的卡片；**分区式**把照片连续铺开、每组开头一条标题与分隔线。按名称排序时中文按拼音。
- **刷新**（`⌘R`，没有选中任何一格时）：重新扫描当前这一层，再按现在的分组 / 排序摆好。文件变化
  偶尔没被自动识别到（网络共享、云盘同步、应用睡着）时用它，不必重开库。
- **放映**：点右上角那颗三角按钮（在「用外部应用打开」左边），按网格顺序自动播放当前这一层，
  默认每 3 秒一张（可在「设置 → 放映间隔」里改），切换时先淡出再淡入。放映中 `←` / `→` 手动翻，
  `空格` 暂停 / 继续，`Esc` 回到网格。
- **用外部应用打开**：标题条搜索框左边那颗按钮，左半直接打开排在最前的一项，右半列出全部。大图页
  上是看图的软件，视频页上依次是 QuickTime Player 与 IINA（装了才有）；照片带拍摄位置时还多出
  「地图」与「Google 地图」，视频有坐标时也一样。网格页给的是当前这一层的文件夹；日历页是系统
  「日历」与 Google 日历。谁排在最前，在「设置 → 外部应用顺序」里按图片 / 视频 / 网格 / 日历分别调。
- **导入**（「文件」菜单）：
  - **导入影片**：Bilibili、YouTube、抖音、TikTok、爱奇艺、腾讯视频、优酷、芒果TV、JavDB、
    Pornhub 十个入口共用一张面板，每行一个编号或链接，可以一次贴一批。网址按域名认来源，裸编号
    按你点进来的入口算。Gallery 用抓到的资料建成影片，并把封面作为新文件存进当前文件夹（不覆盖
    同名文件）。番号打开的网站前缀可在「设置 → 影片网站」里改。
  - **从「演迹」导入…**：把「演迹」导出的 `.xlsx` 演出列表建成事件。
  - 重复导入同一部影片 / 同一场演出会先问你跳过还是全导。
- **设置**：动画速度（慢 / 中 / 快 / 关）、外观（跟随系统 / 浅色 / 深色）、外部应用顺序、影片
  网站、缓存上限、放映间隔，以及「启动时打开上次的库」「打开日志文件夹」与版本信息。动画速度、
  外观、外部应用顺序与放映间隔是整个应用的偏好，影片网站与缓存上限跟着每个库走。
- **最近打开**：菜单底部可以一次清空这份名单（当前正开着的那个库会留下）。用 `.app` 跑时，在 Dock
  图标上右键也能看到同一份名单，跟着系统设置里的「最近使用的项目」走。
- 磁盘上的变化会实时反映到网格：在访达里拖进一批照片或视频、改名、删除，界面自己跟上。

## 支持的照片与视频格式

| | 格式 |
|---|---|
| 元数据**读 + 写**（EXIF / IPTC / XMP 都存得下） | JPEG、PNG、TIFF |
| 元数据能写，但容器存不下 IPTC 那一组地名（只落 XMP） | HEIC / HEIF、WebP |
| 只能写 XMP 里的三层地名（EXIF 与 IPTC 都放不下） | GIF |
| 只能看，改不动 | BMP |
| 视频：浏览、第一帧缩略图、在应用内播放、只读元数据；不写回 | MP4、MOV、M4V、AVI、3GP |
| **尚不支持** | 常见 RAW（CR2/CR3、NEF、ARW、DNG），以及 MKV、WebM 等系统解不开的容器 |

## 已知限制

- 只有**拍摄时间**（含时区）与**位置**（坐标、城市 / 省州 / 国家）可以写回；相机、镜头、
  光圈 / 快门 / ISO 这些拍摄事实一律只读。
- 没装 exiftool 时退回 Pillow 读基础 EXIF，IPTC / XMP 相关的字段不可用，「编辑元数据」也不出现。
- 地点按坐标反查用的是随包分发的离线城市库，**不联网、不上传坐标**。

## 数据与备份

首次打开一个文件夹时，Gallery 会在库根目录下建一个 `.gallery/`，存放自己的运行时数据：

```
<库根目录>/
├── 你的照片文件夹/          # Gallery 不做任何整理
└── .gallery/
    ├── config.toml         # 库级配置（相册封面、界面偏好、影片网站前缀、缓存上限）
    ├── index.db            # 索引缓存，删掉可重建
    ├── events.db           # 事件、封面与照片的关联，删掉就没了
    └── journal/            # 写操作日志，用于回溯与撤销
```

- `index.db` 与 `journal/` 是缓存：删掉后重新扫描就能恢复。
- `config.toml` 是配置，建议自己留个副本。
- **`events.db` 不是缓存**：事件是你自己填的，删掉之后没有任何办法能重建回来。照片与事件的关联
  存的是相对库根的路径，所以把整个库文件夹搬到别处、换台机器或复制一份都还在；备份时请连它
  一起带上。

Gallery 不会往照片目录写 `.gallery/` 之外的东西。应用自己的日志（含出错时的完整调用栈）不在库里，
在 `~/Library/Application Support/Gallery/logs/gallery.log` —— 界面说「详情写进了日志文件」时
指的就是它，报告问题时把它带上。
