# ADR 0017：「拷贝」⌘C 把文件本身放进剪贴板

- 状态：已接受
- 日期：2026-10-06
- 相关代码：`src/gallery/ui/desktop.py`、`src/gallery/ui/menus.py`、`src/gallery/ui/main_window.py`
- 修订：[ADR 0014](0014-context-menu.md) 决策 3 末尾「拷贝文件（⌘C）不做」与「被否决的替代方案」那一行

## 背景

ADR 0014 给右键菜单定下四种落点各自能做什么时，**「拷贝文件 ⌘C」被明确排除**了，理由是：

> 访达认可的「文件引用」剪贴板类型，Qt 的 `QMimeData` 放不进去；真要做就得引 pyobjc /
> NSFilePromise。为一个拷贝动作引入整套原生绑定不值得。

用户后来要看的就是这一条：右键一张照片，访达里有「拷贝」，Gallery 里没有。**当时的理由
经不起复核** —— 下面第 2 条把它推翻了，于是这条记录写下真正的做法。

## 决策

### 1. 放的是**文件本身**，不是路径文字、也不是像素

「拷贝」与既有的「拷贝路径 ⇧⌘C」成对，摆在它上面：

| | 剪贴板上是 | 粘到访达里 |
|---|---|---|
| 拷贝 ⌘C | 文件引用 | **一份拷贝**（源文件分毫未动） |
| 拷贝路径 ⇧⌘C | 路径文字，一行一个 | 粘不进去（是给终端、编辑器用的） |

与访达一致：访达的 ⌘C 放的是文件，⇧⌘C 放的是路径。整个选择（多选时是全部选中项）
一起放，**相册（文件夹）也算** —— 访达拷文件夹是同一件事。

**不选「放像素」**：那是「预览」的做法，粘进聊天窗口里直接是图，但访达里 ⌘V 什么也不会
发生，而且要先解码整幅原图（大照片几百 MB）。本软件的照片都还在用户自己的文件夹里，
用户要的多半是「拿一份到别处去」，文件语义更贴。**不选「两者都放」**：同一条命令的行为
取决于接收方，用户按下 ⌘C 之前无法预知粘出来的是什么。

### 2. 纯 `QMimeData.setUrls()` 就够，不必引 pyobjc

在 macOS 上实测访达 ⌘C 一个文件与 `QMimeData.setUrls()` 各写了些什么到剪贴板：

| 剪贴板类型 | 访达 | `setUrls()` |
|---|---|---|
| `public.file-url` | ✓ | ✓ |
| `NSFilenamesPboardType` | ✓ | ✓ |
| `Apple URL pasteboard type` | ✓ | ✓ |
| `CorePasteboardFlavorType 0x6675726C` | ✓ | ✓ |
| 两个私有的 `dyn.*` | ✓ | — |

**两个公开类型完全一致**，内容也对（`NSFilenamesPboardType` 是装着路径的 plist 数组，
`public.file-url` 是 `file://localhost/…`）。访达另外那两个 `dyn.*` 是它自己的账，
第三方应用没有、也不需要。因此 ADR 0014 的前提是错的，那条「要引原生绑定」的结论作废。

**仍然不做「承诺内容」**（`NSFilePromise` / `com.apple.pasteboard.promised-file-content-type`）：
那是给「文件还没生成、粘贴时才去导」的场合用的，Gallery 里的文件早就在磁盘上了。

### 3. 同一个 `QAction` 同时进「编辑」菜单

沿用 ADR 0014 决策 5：只活在右键菜单里的命令是发现不了也记不住的命令。⌘C 与 ⇧⌘C 挨着摆。

## 后果

- `ui/desktop.py` 多了一个 `copy_files_to_clipboard()`，模块文档里「不提供拷贝文件」那条
  限制删掉，换成上面那张实测对照表。
- 原文件**始终没有被读过一次像素、也没有被改过一个字节**：放进剪贴板的是一个路径引用。
  用户在别处 ⌘V 出来的新文件由访达负责写，不在 Gallery 的地盘上（红线 1 不涉及）。
  「网格上唯一会动用户文件的入口仍然只有重命名与移到废纸篓」这句话不受影响。
- 剪贴板只放引用、不放数据，于是**拷 500 张大照片也只是一次系统调用**，不占内存。
- 非 macOS 平台：同一段代码照常可用（Qt 在 Windows / X11 上把文件 URL 交给对应的文件
  管理器），因此**不加平台分支** —— 与「拷贝路径」一样。

## 被否决的替代方案

| 方案 | 否决理由 |
|------|----------|
| 放像素（`QClipboard.setImage`） | 与访达不一致，访达里 ⌘V 什么也没有；还要解码整幅原图 |
| 文件与像素一起放（像「预览」） | 同一条命令粘出什么取决于接收方，用户按下 ⌘C 前无法预知 |
| 引 pyobjc / `NSFilePromise` | 实测不需要（决策 2）；`NSFilePromise` 是给「粘贴时才生成」的文件用的 |
| 先复制到临时目录再放文件 | 那要自己写文件、还要管临时目录的生命周期；访达拷一个文件本来也不复制 |
| 复制文件**内容**的字节 | 剪贴板里放几十上百 MB 的二进制没有任何接收方会要 |
| 只给照片菜单加，文件夹不加 | 访达拷文件夹是同一件事；「拷贝路径」也早就对文件夹开放了 |
