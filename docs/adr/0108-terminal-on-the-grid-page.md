# ADR 0108：网格页多一项「终端」：在终端里进入当前这一层文件夹

- 状态：已接受
- 日期：2026-10-30
- 相关 ADR：0034（用外部应用打开的入口）、0066（QSpace 那一项）、0067（外部应用按 bundle id 认）、
  0080（次序由用户定）、0094（图片与视频各一份次序）
- 相关代码：`src/gallery/core/external/apps.py`、`src/gallery/ui/desktop.py`、
  `src/gallery/ui/main_window.py`、`src/gallery/ui/window/widgets/external_button.py`、
  `src/gallery/core/locales/`

## 背景

标题条上那个「用外部应用打开」的入口里，「访达」与「QSpace」都在全部照片 / 相册视图下打开
**当前这一层文件夹**。用户要在命令行里处理这个目录（跑 `exiftool`、看目录大小、批量脚本），
于是希望同一处也能开一个终端。

终端与文件管理器不一样：它要的不是「把这个文件夹展示出来」，而是**把工作目录设到这里**。
macOS 的「终端」把递给它的目录参数当成新窗口的初始工作目录，因此 `open -a` 就够。

## 决策

1. **加在这一列里，不加进右键菜单。** 与「访达」「QSpace」是同一个对象（当前这一层文件夹）
   换了个工具，而右键菜单回答的是「选中的这一格怎么处理」。
2. **只在网格页摆。** 大图页要的是「我看的这一张在磁盘上哪儿」，终端进去只会落在这个目录上，
   与用户看的那一张对不上（与 ADR 0066 决策 8 对 QSpace 的判断同一条理由）。
3. **排在这一页的最后。** 访达仍是左半那一下默认打开的那一项，终端是「顺带还能这么开」。
   用户自己排过的次序优先（ADR 0080）。
4. **按 bundle id `com.apple.Terminal` 认装没装**，没装就不摆；图标用系统画好的那一张，
   取不到才退回自画的中性轮廓（别人的图标不随仓库分发，ADR 0034 决策 6）。
5. **命令是 `open -a <终端应用包> <文件夹>`**：目录参数就是工作目录，不拼 AppleScript、
   不往 shell 里插路径。`open` 起不来就改用访达打开并照实说（与 QSpace 同一条降级）。
6. **不碰用户的照片**：只读名册、只起一个 `open` 进程，终端里的后续操作是用户自己的事。

## 后果

- 全部照片 / 相册视图的下拉框里多一项「终端」，排在访达 / QSpace 之后；大图页、视频页与
  日历页上没有它。
- 点一下会开一个新终端窗口（不是只把已有的那个提到前台），工作目录是当前这一层。
- 装没装只在启动时问一次并缓存（与其它外部应用一致），会话中途装上要重开 Gallery 才看得到。

## 被否决的方案

- **用 AppleScript 的 `do script "cd …"`**：要把路径拼进一段 shell 命令，转义一错就是把
  用户目录名当命令跑了；目录参数这条路不经过 shell。
- **`open -a Terminal` 不带参数，再指望它沿用上次的目录**：那是上一次的位置，与这一层无关。
- **大图页也摆**：那里用户关心的是**这一张**，不是它所在的目录；同一个问题里 QSpace 已经用
  「递文件」回答过，终端没有等价的做法。
- **把它塞进右键菜单**：作用对象是「当前这一层」，而右键菜单的第一组作用在选中的照片上。
