# ADR 0071：放映当前层级的照片

- 状态：已接受
- 日期：2026-10-22
- 相关 ADR：0013（暂存与重新分组）、0041（层级栈与 `Esc`）、0051（状态轴）、
  0058（状态归属）
- 相关代码：`src/gallery/ui/window/slideshow_flow.py`、
  `src/gallery/ui/window/state/slideshow.py`、
  `src/gallery/ui/window/widgets/play_button.py`、`src/gallery/ui/viewer/detail.py`、
  `src/gallery/ui/window/viewer_flow.py`、`src/gallery/ui/window/title_bar_flow.py`

## 背景

浏览照片时最常见的用法是「把这一层从头看一遍」。用户已经能用 `←` / `→` 在大图页里逐张翻，
但每一张都要自己按一次；网格里也没有一个入口能替他把当前这一层连续放下去。

需要的东西很小：一个按钮、一段计时、一次淡入淡出。它不该长成第二个浏览界面，也不该把
用户从当前层级带走。

## 决策

1. **复用大图页，不另开窗口**。放映中的画面、缩放、右键菜单、`←` / `→` 都是大图页原有的
   那一条路。放映只负责「下一张是谁」与「什么时候换」，不复制一套视图。
2. **放映期间收起元信息面板**，结束之后按库级偏好 `_metadata_visible` 放回来。用户要的是
   照片本身，不是每三秒换一页资料；同时也不改写用户原来的面板设置。
3. **顺序就是网格里那一刻的顺序**：从模型 `entries()` 里按行取出所有 `PhotoRef`，只认这一批
   照片与它们的顺序，放映途中不重新排序，也不跟随之后的分组变化。**用路径记录进度，不用
   行号**：外部改动可能让同一行指向另一张照片，路径不会。
4. **自动前进每 3 秒一张**，由 `QTimer` 驱动；手动按 `←` / `→` 会重新计时。到头**绕回第一张**，
   于是「一直放下去」不需要另一个开关。**只有一张时不启动计时**，否则只是反复闪同一张。
5. **切换时先淡出、再淡入**：上一张完整地淡出（450 ms），完全消失之后新图才从透明淡入
   （450 ms）。两段之间不重叠 —— 旧画面还没退干净时，下一张一帧都不出现。旧画面盖的是
   切换前的**视口快照**，不在场景里跟着新图重新适配；否则视图改变缩放与中心时，旧图会先
   跳一下。同一张照片的「预览 → 全分辨率」替换不淡入，否则画面会来回闪。
6. **空格暂停 / 继续**；不在放映时，空格仍然是大图页原来的「下一张」。标题条上的那颗按钮在
   放映中变成暂停 / 继续，两种状态各有自己的提示文案。
7. **入口是标题条上的一颗三角按钮**，摆在「用外部应用打开」左边，图标用 Qt 自带的
   `SP_MediaPlay`（放映中换 `SP_MediaPause`），只按主题正文色重新上色。**不倒着长一排新的
   工具条**；这颗按钮与外部按钮同一套药丸外观。
8. **从哪儿开始**：在网格上按放映从这一层的第一张开始；**已经在大图页时，从正在看的那一张
   开始**。两种入口都只放当前这一层的照片。
9. **当前层没有照片时**（例如全是相册或全是分组）弹一句「当前层级没有照片。」，不进入大图页，
   也不留下一个空转的计时器。
10. **结束放映**：`Esc` 结束并回到当前层级的网格（沿用 ADR 0041 在大图页上的退出方向）；
    离开大图页、换层、切库、关库都收掉这一次放映。快照里的照片在途中被移走时也直接结束，
    不拿失效的行号去指别的东西。
11. **日历页不摆放映按钮**。放映的是「这一层的照片网格」，日历页没有这份网格；那里也不该
    拿一份过期的网格模型去放。

## 后果

- 放映没有独立的窗口状态：它只是大图页上的一段模式，`Esc` 之后用户回到原来的层级与网格选区。
- 放映期间换层、切库都会先结束放映，避免旧快照在新模型里找错行。
- 标题条右侧要为这颗按钮多留一格宽度；外部按钮收起时，它直接贴到搜索胶囊左边，不留空位。
- 自动播放间隔与两段淡入淡出时长各自只有一个常量（`AUTO_ADVANCE_MS`、`FADE_OUT_MS`、
  `FADE_IN_MS`），以后要调节只改一处。
- 一次切换共 900 ms（450 ms 淡出 + 450 ms 淡入），在三秒一张的节奏里还不到三分之一；
  手动连续翻页时后一次会从当前可见的那一张重新开始。

## 被否决的方案

- **单独的放映窗口或全屏模式**：多一套窗口、缩放、退出与快捷键要维护，而大图页已经把这些
  做完了。用户要的是「连续看这一层」，不是另一个播放器。
- **按行号记录进度**：实现更短，但放映途中一次外部改名 / 删除就可能让进度指向另一张照片，
  甚至越界。
- **到头就停**：看一整层时最自然的期待是继续绕回去；要停的人按一下空格即可。
- **交叉淡入淡出**：上一张还在退的时候下一张已经露出来。这里要的是「旧画面完全消失之后
  才出现下一张」，所以改成先淡出、再淡入两段，宁可中间短暂露出底色。
- **把放映做成菜单项 / 全局快捷键**：这是浏览动作，不是文件命令；摆在标题条上与「用外部
  应用打开」并排，才和用户此刻看着的那一层在一起。
- **放映时永久关掉元信息面板**：那会改写用户的库级偏好；按偏好恢复才不留下副作用。
- **日历页也放**：日历的时间分桶与网格的照片顺序不是同一件事，放映「当前层级的照片」在那里
  没有明确定义。
