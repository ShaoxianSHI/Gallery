# ADR 0109：放映背景音乐放在库配置里，用 QtMultimedia 播放

- 状态：已接受
- 日期：2026-10-30
- 相关 ADR：0007（Nuitka 自包含包与多媒体后端）、0038（东西只放两个位置）、0073（应用级与库级偏好的分界）、
  0091（视频页的 `QMediaPlayer`）、0100（用户可见文案）
- 相关代码：`src/gallery/core/library/config.py`、`src/gallery/core/library/facade.py`、
  `src/gallery/ui/window/slideshow_music.py`、`src/gallery/ui/window/slideshow_flow.py`、
  `src/gallery/ui/window/settings_flow.py`、`src/gallery/core/locales/`

## 背景

放映时用户希望有音乐。音乐文件在用户自己的磁盘上（可能在库内，也可能在音乐资料库），
Gallery 只该**引用**它，不该复制、转码或修改它。视频页已经在用 `QMediaPlayer`，后端与打包
链路都是现成的。

## 决策

1. **音乐是库级的，写进当前库的 `.gallery/config.toml`。** 键名 `slideshow_music`，空串表示
   不放。每个库可以配自己的一首，换库就换音乐 —— 与「影片网站」「缓存上限」同一层。
2. **路径按库里其它路径的存法**：文件在库内时存相对库根的 posix 路径，库外存绝对路径。
   整份库搬走或复制之后，库内那首歌仍然指得对；库外的歌跟着机器走，换机器需要重选。
3. **读配置不检查文件是否存在。** 音乐可能在一张没挂载的外接盘或尚未同步完的云盘上，
   那不该让整个库打不开。找不到只在放映开始时说一声（横幅），放映继续、没有声音。
4. **播放器只在界面层**：`ui/window/slideshow_music.py` 封装 `QMediaPlayer` + `QAudioOutput`，
   `core/` 仍然不导入 Qt。播放器懒创建，没配音乐的人不会在开窗时多一个解码器。
5. **跟着放映的生命周期走**：开始放映时从头播放；暂停时一起暂停、继续时接着放；结束放映
   （`Esc`、离开大图页、换层、切库、关窗）时停止；下一次放映重新从 0 秒开始。
6. **一首歌循环播放**（`QMediaPlayer.Loops.Infinite`）：放映长度与歌曲长度没有关系，放完就
   静音会让后半段突然安静，比循环更突兀。
7. **音量是应用级偏好**（`music_volume`，0–100，默认 60，界面档位 0 / 30 / 60 / 100）。
   它与放映间隔同类，是「这台机器上怎么放」的偏好，不该跟着库走。
8. **菜单放在「设置」的播放那一段**：「放映背景音乐」（当前文件、选择、不使用）与
   「背景音乐音量」紧跟在「放映间隔」之后。菜单文案中英两份都在 `core/locales/`。
9. **不改音乐文件、不记 journal、不进撤销栈**：播放只读打开文件；设置只写 `config.toml`，
   与封面设置同一类。

## 后果

- 每个库最多一首背景音乐；文件被移动、改名或磁盘没挂载时，那一次放映没有声音并给出可行动
  提示（重新选择音乐文件）。
- 选中的格式能不能解码由 QtMultimedia 后端决定。macOS 上默认后端是 FFmpeg，实测支持
  MP3、M4A/AAC、WAV、AIFF、FLAC；过滤列表只列常见格式，真正兜底的是播放器报错后的横幅。
- 打包不需要新增插件：`--include-qt-plugins=multimedia` 与 FFmpeg 依赖在视频页（ADR 0007 /
  0091）已经带上了。
- 换新歌从下一次放映开始生效；「不使用背景音乐」会立刻停掉正在放的那一首。

## 被否决的方案

- **用 `QSoundEffect`**：只吃 WAV，没有时长与进度，不适合几十分钟的音乐。
- **把音乐复制进 `.gallery/`**：那是缓存目录，清缓存就没了；而且平白多占一份用户文件的
  空间，还绕开了「不接管用户文件」这条边界。
- **存应用级（`state.json`）**：换库时音乐不跟着换，与「这个库配这首歌」的预期不符；用户也
  明确要求写进当前库的 `config.toml`。
- **加载配置时校验文件存在**：外接盘没挂载就整库打不开，代价远大于收益。
- **不循环**：放映通常比一首歌长，后半段无声比重复更明显。
- **把播放逻辑放进 `core/`**：`core/` 不得依赖 Qt；播放器必须留在界面层。
