# ADR 0075：在大图页把拍摄位置开到地图里——只有系统「地图」认坐标

- 状态：已接受（Google 地图那一项由 0076 扩成 PWA）
- 日期：2026-10-24
- 相关 ADR：0034（用外部应用打开）、0067（大图页那一列图片应用）、0021（大图页的当前项）、
  0010（地点按坐标推断）、0077 / 0078（国内坐标先转 GCJ-02）
- 相关代码：`src/gallery/core/external/maps.py`、`src/gallery/core/external/apps.py`、
  `src/gallery/core/external/launch.py`、`src/gallery/ui/main_window.py`、
  `src/gallery/ui/banners.py`、`src/gallery/ui/window/widgets/external_button.py`

## 背景

大图页上已经有「用哪个软件看这一张」。照片带拍摄位置时，还有一件顺理成章的事：**在地图上
看它拍在哪儿**。macOS 上能接管这个动作的应用很有限，本机逐个验过：

| 应用 | 能不能带坐标打开 | 依据 |
|---|---|---|
| 系统「地图」 | 能 | 注册了 `maps` URL scheme；`open "maps://?ll=…&q=…"` 直接定位 |
| 高德地图（Mac 版） | 不能 | `Info.plist` 里没有 `CFBundleURLTypes`；`open "iosamap://…"` 报 `kLSApplicationNotFoundErr` |
| Google 地图 | 只有网页 | Mac 上没有原生应用，官方链接是 `google.com/maps/search/?api=1&query=…` |
| 百度 / 腾讯地图 | 未验 | 两者公开的 scheme 都是 iOS 的，Mac 版没有可依赖的端点 |

## 决策

1. **只加两项：系统「地图」与 Google 地图。** 前者是 macOS 上唯一认坐标的原生地图应用；
   后者给不想用系统地图的人一条路（0076 之后它会优先开在 Chrome 的 PWA 里）。**高德不放进
   菜单** —— 它只能启动到首页，摆进去就是一个点下去没反应的条目（与 ADR 0067 拒绝噪声应用
   同一条判据）。
2. **只在大图页出现，而且这张照片要有真实坐标。** 网格页没有「这一张的坐标」；坐标缺失、
   或经纬度同时为 0（相机没定到 GPS 的占位写法）都不摆。判据与 `is_real_coordinate` 同一份。
3. **坐标先读面板缓存，没有再读索引。** `Library.cached_facets([ref])` 是纯读缓存、不碰
   EXIF，可以在主线程上问；扫描那一遍本来就把坐标存好了。于是不展开元数据面板也点得动。
4. **地图排在「预览」之后。** 左半那一下是「列表里第一个可用的」，把地图排在预览前面会让
   大图页的左半在有坐标时忽然变成地图 —— 同一个位置按下去做的事随照片变化，是最难习惯的。
5. **链接里 `ll` 与 `q` 一起给。** `ll` 只把地图中心挪过去，`q` 才落标记点；只给前者时
   用户看到的是「那附近」，不是「就是这里」。
6. **打不开就照实说。** 复用 `OpenOutcome.detail` 与横幅，文案专用一句「已在地图中打开这张
   照片的拍摄位置」——`external_app_opened` 那句说的是「当前这一页」，对象不对。
7. **图标照 ADR 0034 决策 6 办**：系统「地图」问系统要它画好的那一张；Google 地图画一个中性
   的折页轮廓，不临摹任何一家的商标。

## 后果

- 下拉框在大图页上最多六项：**预览、地图、Google 地图、访达、QSpace、ImageGlass**（装了
  哪几项就摆哪几项）；网格页与日历页不受影响。
- 这一层**不碰照片文件**：只起一个 `open` 进程。
- 非 macOS 上系统「地图」不出现；Google 地图那一项在 macOS 上装了 PWA 就开在应用里
  （0076），否则走浏览器。
- EXIF 坐标是 **WGS-84**，而中国境内的地图底图是 **GCJ-02**。Apple 地图实测会把坐标换算到
  底图上（天安门 WGS-84 坐标落点仍标「东城区」，没有往西偏到西城区），但这是粗验证；Google
  地图在中国大陆的偏移情况不一致。发版前应拿一张国内拍的照片对照一次，不要只看国外的点。
  若以后要接高德 / 百度，必须自己做 WGS-84 → GCJ-02 / BD-09，不能把 EXIF 的坐标直接递过去。

## 被否决的方案

- **把高德地图放进来**：它的 Mac 版不接受带位置的链接（见上表），只能启动到首页。摆一个
  点下去什么都不发生的条目比没有更糟。
- **用 `https://maps.apple.com/?ll=…`**：它是网页地址，开在哪儿要看系统与浏览器怎么分派；
  `maps://` 明确交给那个应用（本机实测直接定位）。
- **网格页也摆**：那一页没有「正在看的那一张」，要先定义「选区里的每张各开一个地图窗口」，
  那是另一件事。
- **地图那一项排在最前（让它做左半默认）**：有坐标的照片上左半会变成地图，没有坐标的又是
  预览，同一个按钮的行为随内容变化。
- **自己从应用包里拆地图图标**：见 ADR 0034 决策 6 / 0067 决策 8 那圈白边。
