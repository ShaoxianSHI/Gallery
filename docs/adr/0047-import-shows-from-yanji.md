# ADR 0047：从「演迹」导入演出 —— 读它导出的 .xlsx，一批建成演出事件

- 状态：已接受
- 日期：2026-10-07
- 相关 ADR：0043（事件体系）、0045（演出这一类）
- 相关代码：`src/gallery/core/events/import_shows.py`、`src/gallery/core/library/facade.py`、`src/gallery/ui/window/event_flow.py`

## 背景

「演迹」能把演出列表导出成一张 `.xlsx`：一张工作表、一行一场，表头是中文列名 —— 前 15 列是演出（演出名称 / 艺人 / 嘉宾 / 主题·剧目 /
日期 / 城市 / 场馆 / 票价 / 实付 / 座位 / 标签 / 评分 / 演出类型 / 购买渠道 / 感想 / 备注），后 5 列是另一类东西（活动名称 /
活动时间 / 花费 / 活动地点 / 活动备注）。要定三件事：入口放哪、这个表格怎么读、读出来的东西算不算「用户文件」。

## 决策

### 1. 入口在「文件 → 导入演出 → 从「演迹」导入…」，解析与写库分两层

菜单栏「文件」里多一层子菜单，挨着「打开文件夹」—— 两者都是「把外面的东西拿进来」。点下去挑一个 `.xlsx`，Gallery 把里
面每一行建成一条**演出事件**。解析在 `core/events/import_shows.py`（纯函数，不碰事件库也不碰 Qt），写库是
`Library.import_shows(path)`：它逐条走既有的 `create_event`，于是 journal、缓存作废与新建事件那条路完全一致。

### 2. xlsx 用标准库读，不为一件小事引第三方依赖

一个 `.xlsx` 就是一个 zip，里面 `sharedStrings.xml`（共享字符串）与 `worksheets/sheet1.xml`（工作表）两张 XML，用
`zipfile` + `xml.etree` 直接读够这一层用，核心层不多一个依赖，也就不必为它写一条 ADR 之外的打包说明。

### 3. 列按中文表头认；缺列不算错，少了「演出名称」才报错

表头是名字而不是位置：版本之间列会增减，按位置读会在某一版悄悄错位。**认不出的列直接忽略**（「标签」就没有对应字段），
但连 `演出名称` 都没有的话看起来根本不是这个格式 —— 那时抛 `ShowImportError` 说清楚，而不是猜着读下去。**没有演出身份
的行跳过**：只有「活动」那几列时它是另一类东西，连名称 / 剧目 / 艺人都没有时也记不成一场演出；跳过的几行在横幅里报个数
（行号与原因进日志）。

### 4. 日期只取整天，开场时间留空

「日期」那一列在 Excel 里是串号（从 1900 年起的天数），**小数部分**是导出里那个时刻。但它的显示格式本身只到天（`numFmt` 14），
而且那串小数还原成本地时间要先假定一个时区 —— 假定错了会静默写进一个错的开场时间。**错的时间比留空更糟**，所以本层只取
整数部分当日期。

### 5. 导入 = 一串新建事件，不进撤销栈，一个用户文件都不碰

建事件本来就不上 `⌘Z` 那一摞（撤销它就是删），一次导入因此也不进：导入错了去事件清单里逐个删。导入只写 Gallery 自己的
`.gallery/events.db`，不碰照片（约束 1）。

### 6. 重复不静默处理：写库之前先预演一次，再问用户一句

导出的行里没有稳定唯一的 id，判重只能靠内容：**名称 + 日期 + 场馆**三样都相同即视为重复。
`Library.plan_show_import(path)` **只读不写**，算出表格里几场与库里已有的重复；界面发现重复数大于 0 时弹一个框，让用户选
「跳过重复 / 全部导入 / 取消」（默认「跳过重复」），选完才调 `Library.import_shows(plan, skip_duplicates=...)` 真正写。
**为什么让用户选而不是自动跳过**：同名同日同场馆确实可能是两场（联票、加演），自动跳过会悄悄吞掉一场 —— 预演 + 确认既让
「同一个文件导两次」接近幂等，又把判断交回给唯一知道实情的人。

## 后果

- 从「演迹」导出、到在 Gallery 里按演出挑照片，只差一次导入。判重只认名称 + 日期 + 场馆，同名同日同场馆真的有两场时会
被当成重复 —— 这时选「全部导入」。「标签」列不导入；开场时间留空；活动那几列不导入。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 引入 `openpyxl` / `pandas` 读表 | 一个工作表、两张 XML 的事，为它背一个第三方依赖不划算 |
| 按列的位置（A/B/C…）读 | 版本之间列会增减，错位时静默写错字段 |
| 把串号的小数按 UTC 还原成本地开场时间 | 要假定一个时区，跨机器会写进错的时间（决策 4） |
| 静默按内容去重（不问用户） | 同名同日同场馆真的有两场时会悄悄吞掉一场 |
| 导入进撤销栈（一次 `⌘Z` 撤销整批） | 与「新建事件不进栈」这条既有规矩冲突，且绑定 / 撤销要跨十几条记录 |
