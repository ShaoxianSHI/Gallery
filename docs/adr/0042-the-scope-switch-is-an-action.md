# ADR 0042：作用域切换按钮是一次性动作，不摆选中态

- 状态：已接受
- 日期：2026-10-06
- 取代：[ADR 0040](0040-filter-within-the-current-view.md) 决策 5 里「**一个可勾选的按钮**」与「选
  中时整枚按钮填满高亮色」那两句，以及「按钮不挂悬浮提示」的那条理由
- 相关 ADR：0040（筛选：在当前视图内收窄）、0035（颜色只从一处解析）、0041（「我在哪」是一条栈）
- 相关代码：`src/gallery/ui/window/widgets/search_field.py`、`src/gallery/ui/main_window.py`、
  `src/gallery/ui/window/search_flow.py`

## 背景

ADR 0040 决策 5 那枚按钮是**可勾选**的：整枚按钮填满高亮色（`palette(highlight)`），想法是「唯一的
『现在开着吗』信号就是那一片颜色」。但它做的是「掉个头」，按下去之后剩下的事全都已经发生了，那一片
颜色于是**上一件事的结果**而不是「此刻是哪一头」—— 它长得像一台开关，实际是一次性动作。

## 决策

### 1. 按钮不再有「选中 / 未选中」两态，它是一次性动作

`ScopeToggle` **不再 `setCheckable`**，也**没有** `set_filtering`：两种作用域下它长得一模一样 —— 同
一个底色（输入面那一档 `field_background`）、同一枚图标（墨色恒为 `text_at(0.55)`）、同一圈轮廓，按
一下就是「掉个头」，不留在任何一态上。

**「此刻是哪一头」说在另外两处**，两处都是本来就在的：

| 位置 | 说什么 |
|---|---|
| 胶囊里的占位文字 | 「搜索照片…」/「筛选照片…」（ADR 0040 决策 5 的那两句，两句一眼能分） |
| 菜单里「筛选当前视图」那一项 | 勾（**这一项已由 [ADR 0069](0069-scope-switches-only-from-the-toggle.md) 删掉**） |

状态仍照旧是**库级偏好**、仍由 `set_search_scope` 这一个入口改、仍然记在 `config.toml` 的
`[ui]`（ADR 0040 决策 6）—— 变的只是它不再**显示**自己。**方向由外面算**：`switched` **不带参数**，
「掉个头」在 `MainWindow._on_scope_switched` 里按当前 `_search_scope` 取反；按钮自己不记状态，记下
来就等于变回开关。

### 2. 按钮**仍然不挂悬浮提示**

ADR 0040 决策 5「不挂提示」的理由随决策 1 一起失效，所以这条要重新给理由：

- **它没有状态可说** —— 提示能说的只有「按下去会做什么」，而两支反向箭头说的正是这件事；
- **「此刻是哪一头」紧挨着就写着** —— 占位文字就摆在左边一格，再挂一句提示是在把同一件事说两遍；
- 回归测试从「按一下之后仍然是空的」改成断同一件事（`test_the_button_has_no_hover_hint`）。

### 3. 反馈改由**按下**给出，而不是由**状态**给出

按钮自己不变，于是必须给一点**瞬时**反馈：`:pressed` 把底色提亮一档（深色下 `lighter(112)`、浅色下
`darker(104)`，与「外部应用」药丸的悬停提亮同档），悬停仍由 `paintEvent` 自己画轮廓（高亮
色，`draw_outline` 那条路，理由见 `ui/outline.py`）。**这三档仍然只是同一个矩形的常态、悬停、按
下**，**不引入第四档**，也**不把悬停提亮搬进按下** —— 按下要的是「我按到了」，不是「我在它上面」。

### 4. 回归测试从「选中时填满」换成「两档一模一样」

`test_selecting_the_button_fills_it_not_just_its_edge` 连同它断的那件事一起去掉，换成
`test_the_button_stays_the_same_in_both_scopes`：**两档各量一次按钮中心那一块的像素**（`grab()` 取
中心那一格），断它们相等、且都不是 `Highlight`；再补一条
`test_pressing_the_button_twice_comes_back`，**按两下回到原处**，断「掉个头」的语义，且因为**按的是
真的按钮**而顺带断「信号接上了、按钮没被置灰」。

## 后果

- `ScopeToggle` 少三个字段（`_active`、`_applied_active`、`set_filtering`），信号由
  `toggled(bool)` 变成 `switched()`，`toggle_style` / `scope_arrows` 少一个 `active` 参
  数；`_sync_search_scope` 同步**两处**（占位文字与菜单勾，后者已由 ADR 0069 删掉），`_on_scope_toggled(filtering)` 变成
  `_on_scope_switched()`，判据从信号带来的 bool 变成「当前作用域取反」。机制**一个字没变**（仍是
  ADR 0040 决策 1 的两档、库级偏好、单一入口、不清条件）。
- 测试：`tests/ui/test_filter_flow.py` 那一族换一条加一条，其余用例改用 `click()`（**要开着库**）。

## 被否决的替代方案

| 方案 | 否决理由 |
|---|---|
| 保留勾选态，但让**图标**两样（搜索 ⇄ 筛选各自一枚） | 两枚长得不一样的图标读起来像两个功能（ADR 0040 决策 5 已经因为这个理由用过同一枚）；而它们是同一个动作的两端 |
| 保留填充色，改成「显示下一次按下去会切到哪一头」 | 那就不是「此刻是哪一头」了，而占位文字已经在说此刻 —— 标题条上于是有三个说法，其中两个说的不是同一件事 |
| 两段式分段控件（搜索 \| 筛选） | ADR 0040 已经否决过一次（胶囊左边要多长一截，且两格共享圆角轮廓要另写一遍绘制） |
| 按钮不摆状态、提示改成「按下去会做什么」 | 占位文字就在左边一格，两支反向箭头已经说了「掉个头」（见决策 2） |
| 干脆删掉按钮，只留菜单里那一条 | 作用域是这一族里用得最频繁的一次切换（「这一屏里没 Canon 的都去掉」），藏在菜单里等于把它埋了 |
