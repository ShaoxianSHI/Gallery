# ADR 0111：删除照片与相册时播放 Finder 的「移到废纸篓」音效

- 状态：已接受
- 日期：2026-10-31
- 相关 ADR：0007（自包含包）、0021（大图页上删除）、0109（放映背景音乐）
- 相关代码：`src/gallery/ui/desktop.py`、`src/gallery/ui/write_ops.py`、
  `tests/ui/conftest.py`、`tests/ui/test_trash_flow.py`、`tests/ui/test_desktop.py`

## 背景

用户在访达里把文件拖进废纸篓时会听到那一声「揉纸」，Gallery 里删除照片与相册却是安静的。
两者做的是同一件事（移到系统废纸篓，可撤销），反馈却少了一半。用户希望补上。

这一声属于 macOS 的系统音效：Finder 删除时请求的是系统音效表的第 16 项，对应
`.../SystemSounds/dock/drag to trash.aif`；**不是**名字更像的
`.../SystemSounds/finder/move to trash.aif`（第 14 项），那一项对应另一条动作。
这一点是看 `systemsoundserverd` 的日志确认的：Finder 删除时 `actionID` 是 16，
加载的正是 `dock/drag to trash.aif`。

## 决策

### 1. 调用系统音效表，不把声音文件带进仓库

用 AudioToolbox 的 `AudioServicesPlaySystemSound(16)` 播放。**不复制、不内嵌**那个 `.aif`：
它是 Apple 的系统资产，进仓库既有授权问题，也让安装包平白多一份二进制；而系统自带的这一份
本来就会跟着 macOS 更新。

`16` 不是公开常量，但 Apple 从 10.5 起一直用这个值。它只是外观反馈，**认错了最多是没声音
或响错一声**，不值得为它维护一份文件路径与解码器。

### 2. 开关和音量都交给 macOS

`AudioServicesPlaySystemSound` 走的是系统音效通道，所以：

- 系统设置里关掉「播放用户界面声音效果」，这里不会出声；
- 音量跟着系统的提示音音量走。

于是**不再做一个应用内的开关**：访达自己也只有一个系统开关，两处各管一半只会让用户
找不着「到底哪儿关的」。

### 3. 只在真的移走之后响，且只响一次

调用点在 `write_ops.trash_selected` 拿到 `move_to_trash` 的结果之后：

- 至少有一项真的离开了原位才响；
- 一项都没移走（文件不在了、被占用）不响 —— 那一声在用户听来就是「删掉了」；
- 撤销取回、改名、编辑元数据一律不响；
- 一次删十张只响一声，与访达一次操作一声一致。

照片与相册走的是同一个入口（选中的 `FolderRef` 也交给 `move_to_trash`），因此一处接入
两处生效。

### 4. 播放器留在界面层，失败不打扰写操作

加载 AudioToolbox 与播放都在 `ui/desktop.py`，`core/` 仍然不碰平台音频。第一次播放时才加载
框架；非 macOS、框架缺失、没有音频设备都只记一条 debug 日志，**删除照常完成**。这段代码
不读也不写用户的照片，不记 journal，不进撤销栈。

### 5. 测试里不许真的响

`tests/ui/conftest.py` 的 autouse fixture 把 `_play_system_sound` 换成一个记录器：并行跑一轮
就是几十声，而且没有断言能看见它。要验「删掉时响了一下」的用例拿这份记录断言，播放器本身
另用假实现单测。

## 后果

- 删除照片与相册会响一声，行为与访达一致；关掉系统音效后一起安静。
- 不新增依赖、不新增权限、不新增文案、不新增二进制资产。
- 测试不会发出声音，也不会因为这台机器没有音频设备而失败。
- 若 Apple 将来改掉系统音效表的编号，这个功能会静默失效；改文件路径方案是备选，但需要在
  路径变动时自己找文件。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 把 `drag to trash.aif` 打进安装包 | Apple 的系统资产，授权不明；也不跟系统的音效开关与音量走 |
| `NSSound` 播放同一个文件 | 需要自己读「播放用户界面声音效果」与提示音音量，还得保住对象直到播完 |
| `afplay` 子进程 | 每删一次起一个进程，有启动延迟，而且绕开了系统的音效开关 |
| `QSoundEffect` / `QMediaPlayer` | 前者只吃 WAV，后者为半秒的音效建一套播放器；两者都不跟 macOS 的音效开关 |
| 在删除开始时响 | 操作可能失败，那时声音已经在说「删掉了」 |
| 应用内再加一个开关 | 系统设置里已经有一个，两处开关会让「去哪儿关」变得不确定 |
