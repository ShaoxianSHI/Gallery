# ADR 0031：位置的双向编辑 —— 坐标推地点，地点推坐标

- 状态：已接受
- 日期：2026-10-06
- 相关 ADR：0003（离线反查）、0010（打开时解析入库）、0011（地点语言规则）、0012（自带城市库）、0030（写回原文件）
- 相关代码：`src/gallery/core/places/dataset.py`、`src/gallery/core/places/resolver.py`、
  `src/gallery/core/metadata/place_edit.py`、`src/gallery/ui/dialogs/metadata_edit.py`
  （原名 `place_edit.py` / `PlaceEditDialog`，ADR 0032 随「编辑元数据」一起改名）

## 背景

Gallery 一直只有「坐标 → 地点」这一路（ADR 0003）：相机原图几乎不写地点，按 GPS 反查一次，把国家、省
州与城市补齐进索引（ADR 0010）。允许编辑位置之后（ADR 0030），两个方向都缺：坐标改了而地点名还写着旧
城市，或改对城市名而 GPS 还固定在别处。而「地点 → 坐标」这一路城市库原本**没有**（`PlaceIndex` 只有 `nearest()`）。

## 决策

### 1. 两条方向在同一个对话框里合流

`PlaceEdit` 收到的是「用户填完的**那一份**」，不是「改了哪些」—— **打开时就把照片此刻的值全填上**（
访达「简介」的用法）。

| 用户动的地方 | 顺带发生什么 |
|---|---|
| 坐标 | 按新坐标反查地点（`place_for`），查到了就一并写进去 |
| 地名 | 按新名字正查坐标（`place_named`），查到了就一并写进去 |
| 两个都动 | **用户填的说了算**，不去反查覆盖他 |
| 只清空坐标框 | 删坐标、留地名（定位漂了而地名没错） |
| 三层地名与两个坐标框**全清空** | 坐标与三层地名一起删 —— 不需要单独的勾选框 |

### 2. 「地点 → 坐标」用城市库自己的名字，正查就够

`PlaceIndex.by_name(name, region=, country=)`：精确名 → 「市 + 省」→ 「市 + 国家」→ 只看市名；多候选**按人口降序**返
回，让用户在补全里挑一个（同 `nearest` 的消歧理由）。匹配从最具体到最宽，因为同名的城市成百上千。三
张名字索引在加载时一次建好，查询是查表而不是遍历两万条 —— 那一路是用户**边打字边问**的。**不联网、不改数据、不引入新依赖**：
名字按 ADR 0011 在生成期就定好了。

### 3. 查不到就是查不到，绝不编一个坐标

库里没有的名字（用户自己写的门牌、景区、小店）**只写地名、坐标原样不动**，并说清「城市库里没有这个名
字，坐标保持原样」。这句话后面还跟了半句：**境外地点按当地写法收录（京都写作 `Kyoto`）** —— 不说它，
用户输「京都」查不到只会以为这个功能坏了，而 Gallery 显示境外地名用的就是当地写法（ADR 0011）。

### 4. 坐标 → 地点查不到时，**保留**原来的地名

坐标挪到了海上、附近 300 公里没有城市（ADR 0012 的硬上限），照片里原来写着「南京」。**不清空**：那张
照片本来就是「南京」，用户只是把坐标挪到了别处 —— 是地名错了还是坐标错了该由用户判断，替他删掉只会让
事情更难查。

### 5. 由地名反推出来的坐标是**市级精度**（这一条现在是**只做不说**）

城市库里那一条坐标是这座城市的位置（多数是市质心），不是这张照片的拍摄点；把几十米的精度换成几公里，
是一个**看起来精确、实际很粗**的值。对话框里**不做预告**，横幅也不要：「先说再写」这一半不成立，风险
由两处兜着 —— **坐标系整体只有 13 个标签可写**，以及**每一次写入都能 `⌘Z` 逐字段撤销**；这是「知道后
果不如能改回来」的取舍。对话框里**一个勾都没有**：这个联动就是「编辑位置」存在的意义，为它留一个勾等
于让用户每次都要决定一遍要不要联动。「清除位置」同样不需要 —— 三层地名与两个坐标框全清空就是那个意思。

### 6. 编辑坐标时顺手清掉海拔与定位时间

那两条记的是**另一个位置**上的测量值：坐标在杭州、海拔是珠峰的，一条 GPS 记录内部就自相矛盾了。清掉
比留着好 —— 它随坐标编辑一起发生，同样能被 `⌘Z` 撤销。

### 7. 编辑器里两个方向都是**实时**的

三个地名框按**国家 → 省 / 州 → 城市**排，而真正用来查的是**城市**（省与国家只是收窄同名的条件）。

- **只敲城市就行**：城市一敲定，上面两栏自动补上；查不到时**只按名字再查一遍** —— 用户换城市时那两栏
  还留着**上一座城市的**省与国家，按过期范围查当然查不到；
- **少于两个字不查、也不给候选**：城市库里有一条真叫「苏」的条目，敲下第一个字就恰好命中，跳出来的是
  「中国 · 安徽省」和一串坐标 —— 数据里的碎片，不是用户要填的地方；
- **敲地点 → 坐标框立刻更新**；**敲坐标 → 地名框立刻更新**；
- 程序自己填进去的框不再触发下一次回填（`_programmatic` 标志挡住），否则会自己打起来；
- 查不到就**一个字都不填**，说明那一行如实说「城市库里没有这个名字，坐标保持原样」；
- 说明那一行**按「用户刚才动的是哪一侧」说话**：自动回填改了两侧，「哪一侧变了」不再有用；
- 取消「同时按这个地点更新经纬度」时，刚才自动填进去的坐标**还原成照片原本的** —— 框里显示的必须是真
  正会被写下去的那一份。

### 8. 面板上三层地名写成一行

文件里写了地点之后，面板的「位置」组**一行**说清：`中国 · 浙江省 · 杭州`。分三行摆着看着像三件无关的
事，而它们说的是同一个地方 —— 与推断出来的地点同一个说法（「地点（推断）」也是一行）。子地点是另一个
字段，仍单列。既有问题一起修掉：**exiftool 的 `-G` 按一级族回填键**，13.x 给的是 `XMP:City` 而不是 `XMP-photoshop:City`。
只认全名的话，Lightroom 那种只写 XMP 不写 IPTC 的照片「地点」永远是空的 —— 面板、分组与索引三处都改
成两种族名都认。

### 9. ⌘W 关它，窗口不能拖大拖小

⌘W 挂在对话框自己身上（`StandardKey.Close`）：不挂这一条它会一路走到主窗口 —— 在一个模态框里按 ⌘W 结
果整个窗口没了。窗口尺寸由 `QLayout.SetFixedSize` 锁定，说明与错误各留固定的两行高度，免得文案换来换
去时对话框长高再缩回。

### 10. 横幅只有一句，不重复对话框

保存之后横幅上**只有**「已更新「一张.jpg」的位置。⌘Z 可以撤销。」。横幅只回答两件事：**成了吗**、**能不能撤**。
后者不是重复：它不是「发生了什么」，而是「你刚才按 ⌘Z 会发生什么」；撤销时的「只撤了一部分」同理 ——
那是结果，不是解释。因此 ``PlacePlan`` 上不再带任何「要说的话」：这一层只负责**哪些字段会被改**。

### 11. 冲突由用户填的解决

坐标与地名都被改过时，不去反查也不警告「它们不一致」：那不是错误，是一种合法的用法（给扫描件补个大概
位置）。

### 12. 按钮：复制 / 粘贴 / 清空一行，取消 / 保存一行

第一行三个键**占满整行**（各占三分之一），第二行「取消 / 保存」**分别与粘贴、清空对齐**，宽度与位置
由布局算出。「清空」按钮取代了那个「清除位置」勾选框：勾选框得先去勾一下才生效，放在五个按钮里反而更
像一个动作；而「全清空」本来就是编辑器里唯一表达得出「全删」的形状。它**只清框**，仍然要按保存才写盘。
对话框里不再有任何预告行（「保存后，XXX」）。

### 13. 入口摆在页脚，不摆在「位置」那一组里

入口原本摆在「位置」那一组标题右边，而**没有位置的照片压根不会渲染出那一组** —— 想给一张没位置的照片
补位置时界面上什么入口都没有。于是它挪到页脚，与「复制全部」「显示全部字段」一行，**三个组件平分整行**（
两个按钮 ``Expanding``，那个勾选框按自己的宽度）。不能用时（没装 exiftool）**置灰**并把理由放进悬浮
提示，而「位置」那一组仍然把那句话写出来（ADR 0014 决策 4）。

## 后果

- 城市库多占一点内存：两张名字索引约两万来个键、几 MB，一次建好全程复用。「地点」从此**只有一套算法**：
  反查（`nearest`）与正查（`by_name`）读同一份文件与同一份语言规则，补全、面板、分组说的是同一种话。
- 编辑器的输入是一份**最终状态**，因此任何调用方都必须像对话框那样把三层地名与坐标都带上 —— 少带一个
  就会被解释成「清空那一层」（由 `test_place_edit.py` 的 `fill()` 盯着）。

## 被否决的替代方案

| 方案 | 否决理由 |
|------|----------|
| 编辑坐标时把旧地名一并清空 | 那是替用户决定「哪个错了」；保留并说明更诚实（见决策 4） |
| 地名查不到时也配一个坐标 | 库里没有的东西不该由我们编；一个错得离谱的坐标比没有坐标更坏 |
| 地名查不到就干脆不让保存 | 用户完全可以只改文字描述；那是他要的事，不该被工具拦下 |
| 用在线地理编码服务做正查 | 坐标与地名一个字节都不出本机是 ADR 0003 的承诺；而且那需要联网 |
| 编地名时保留原坐标（默认） | 用户明明白白写了「苏州」，界面里那行字还指着南京 —— 两处说两套话（见决策 1） |
| 引入地图控件让用户点选 | 这是唯一会破坏「坐标一个字节都不出本机」的功能。真要做，宁可先做「用地图 App 打开、复制坐标回来」 |
| 编辑地点时一并改同组照片 | 一次动几百张照片的 GPS 是不可想象的操作 |
