# ADR 0069：作用域只从胶囊右边那枚按钮切换

- 状态：已接受
- 日期：2026-10-22
- 相关 ADR：0040（筛选：在当前视图内收窄）、0042（切换按钮是一次性动作）
- 相关代码：`src/gallery/ui/main_window.py`、`src/gallery/ui/window/search_flow.py`

## 背景

「文件」菜单里还有一个可勾选项「筛选当前视图」，与胶囊右边那枚按钮走同一个入口（ADR 0040 决策 5）。
ADR 0042 决策 1 把按钮改成一次性动作之后，这一项成了菜单上唯一显示「此刻是哪一头」的地方。

但它与按钮重复：同一个动作两条路，而菜单里那一条还让「文件」多出一项与文件无关的勾选。
作用域始终可以从胶囊旁边那一枚按钮切换，菜单项没有提供按钮给不了的能力。

## 决策

1. **删掉「文件 → 筛选当前视图」这一项**，连同它的 `QAction` 与 `toggled` 连线。作用域只从胶囊
   右边那枚按钮切换（ADR 0042）。
2. **「此刻是哪一头」只说在胶囊的占位文字里**（「搜索照片…」/「筛选照片…」）。ADR 0042 表格里
   「菜单里那一项 | 勾」那一行随之作废。
3. `_sync_search_scope` 只同步占位文字，以及那几份跟着作用域走的菜单文案（「搜索… / 筛选…」、
   「清除搜索条件 / 清除筛选条件」），不再同步任何勾。
4. 回归测试改成 `test_the_file_menu_no_longer_offers_the_scope`：文件菜单里不再出现那一项。

## 后果

- 切换机制一个字没变：仍是一次性动作、仍是库级偏好、仍由 `set_search_scope` 一个入口改
  （ADR 0040 决策 1 / 6、ADR 0042）。
- README 的快捷键表格不再提那条菜单路径。
- `MainWindow` 少一个 `_scope_action` 字段，`SearchFlowMixin` 的宿主契约表同步收掉它。
