# ADR 0107：大图页底部的画廊条

- 状态：已接受
- 日期：2026-10-28
- 相关 ADR：0001（解码分层）、0015（缩略图流水线）、0021（大图页）、0060（三份缩略图缓存）、
  0091（视频页没有缩略图导航）、0096（底色只有一个主人）
- 相关代码：`src/gallery/ui/viewer/filmstrip.py`、`src/gallery/ui/viewer/detail.py`、
  `src/gallery/ui/window/viewer_flow.py`、`src/gallery/ui/window/thumbnail_flow.py`

## 背景

大图页只显示当前这一张，翻图只能按 `←` / `→`，看不到自己在当前层里的位置，也没法直接跳
到几张之外。用户要的是访达「画廊」那种体验：照片下缘浮一排缩略图，当前那张选中并尽量居中，
点哪一张就换到哪一张。

## 决策

### 1. 浮在照片下缘，不进任何布局

它是 `DetailView` 的子控件，位置由纯函数 `strip_rect` 算：水平居中、最宽 1180 点、
离底边 28 点。**不进布局**：进了布局就会把照片往上挤，翻图时照片的适配尺寸也跟着变。

**视频页没有这条面板**：沿用 ADR 0091 决策 3 —— 看视频要的是画面。它是 `DetailView` 的
子控件，`_show_video` 把视图 `hide()` 时面板一起收起来，不需要另一套显隐判断。

### 2. 顺序就是这一层的模型行序

条目从模型的行号取，**跳过相册与分区标题**（它们不是照片）。当前那张左右各取 16 张，
到这一层的头尾时自然短一截；居中由 `centered_offset` 夹在 `0 … 内容宽 − 视口宽` 之间，
于是中间严格居中、两端贴边。**不维护「照片在这一层里排第几」**：那要一次遍历整层，
而窗口只需要看得见的那几张。

### 3. 缩略图复用网格那一份缓存

面板要的图与网格是同一个 `PhotoListModel.thumbnail_pixmap`，档位也跟网格走（`icon_edge`）。
**不新开第三份缩略图缓存**（ADR 0060 已经把「三份」说清）：模型只按路径存一张，换一个档位
就会把网格那份也作废，切回网格要整屏重解码一遍。面板绘制时按目标矩形平滑缩放（与网格委托
同一做法），**不额外产出中间位图**。

取图仍走同一条流水线（ADR 0015）：视口里的先出图，两侧备用的排后面；`set_window` 是整份
替换，离开大图页时由网格那一支重新声明。

### 4. 点击与 `←` / `→` 走同一条路

点一格只发一个行号，窗口收到之后和翻图一样：清横幅、改 `_current_row`、`_load_detail(row)`。
**不新开页面栈**：照片帧还压在栈上，`Esc` 仍然退回进入大图之前那一层。

### 5. 更新挂在 `_load_detail` 与重排之后

换照片的五条路都会经过 `_load_detail`，面板在那里取新的一批。重排（监听器、换排序）会改
行号，所以 `_reorder_level` 改完模型之后也重取一批。`_sync_ui` 不收它 —— 那里只放纯映射，
而面板要取图、要读缩略图缓存。

### 6. 视觉

半透明主题底色（不透明度 0.82）压住照片，当前格用链接色描 2 点轮廓。**自己铺这一层**是
有意的：它确实要盖住照片，所以 `mark_see_through` 之后在 `paintEvent` 里画；这与「其余各层
都不铺底色」（ADR 0096）不冲突。

### 7. 「显示」菜单里能关掉，默认开着

偏好是应用级的（`Preferences.show_filmstrip`，与「显示文件扩展名」同一类）：换库不重置，
菜单项就摆在「显示文件扩展名」上面。关掉只是收起面板并停止替它排队取图 —— 已经摆好的那一批
留在控件里，再打开立刻回来，不必重扫这一层。

## 后果

- 进入大图页时最多向流水线要 33 张缩略图，都落在模型那 64 MB 预算里；连续翻图只补两端的新图。
- 只有一张照片的层不显示面板（没有可导航的东西，白白压住画面）。
- 面板本身不能自由滚动：它只负责把当前那张摆在中间。要滚动看更远的照片，先点一张过去。
- 面板宽度封顶，超宽窗口上两侧会留出空白；换来的是当前那张始终能真居中。

## 被否决的替代方案

| 方案 | 否决理由 |
|---|---|
| 用 `QListView` + 自己的模型 | 这一层有相册与分区标题，先要过滤一遍；居中与「两端贴边」仍得自己算 |
| 把面板放进 `detail_layout` | 照片会被往上挤，翻图时适配尺寸变化一次，画面像是缩了一下 |
| 为面板另开一份缩略图缓存 | 同一张照片在内存里存三份（网格、日历、面板），换档还要各自淘汰 |
| 面板自由横向滚动 | 当前那张的居中与用户滚动要合成一个状态；这一版先用「点一张看几张」 |
| 视频页也摆这条面板 | ADR 0091 已经定过：看视频要的是画面，不在播放器下面放缩略图 |
