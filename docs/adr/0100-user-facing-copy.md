# ADR 0100：用户可见文案的口径

- 状态：已接受
- 日期：2026-10-25
- 相关 ADR：0073（设置菜单）、0098（背景图）、0099（设置菜单按话题分段）
- 相关代码：`src/gallery/ui/banners.py`、`src/gallery/ui/desktop.py`、
  `src/gallery/ui/dialogs/`、`src/gallery/core/*`（抛给界面的中文消息）

## 背景

文案是东一句西一句长出来的：同一个结果有「没能」「没法」「还没」「没有找到」四种说法；
指代靠上下文（「这一档回到背景色」离开菜单就不知道指哪一档）；错误信息里既有「腾出点空间
再试」这样的口语，也有「它可能已被移动、重命名或删除」这样的书面语。**用户读到的语气取决于
当初是谁写的**，而这不是产品选择。

创建背景图之后，横幅写的是「这一档回到背景色」—— 它既没说哪一档，也没说「纯色」与「背景色」
是不是同一件事。这说明缺的不是个别句子的润色，而是一份能照着写、也能照着改的口径。

## 决策

### 1. 用书面语，结果词只有三个

| 用 | 不用 |
|---|---|
| 未能（做了一次，没成功） | 没能 |
| 无法（条件不支持，做不了） | 没法 |
| 尚未（状态还没到） | 还没 |

`尚未` 后面接动词原形（尚未打开库），**不写「尚未有」** —— 那是两个口语词叠在一起。

### 2. 指代必须点名

横幅与错误信息里不许出现「这一档」「那个」「它」这种离开现场就指不清的说法：

- 「浅色背景已改为纯色。」「深色背景已设为「晨雾」。」
- 「该事件已不存在。」（不写「这个事件已经不在了」）
- 「「索引.jpg」所在位置已有其他文件。」

**判据**：把这句话单独贴进一条聊天记录，读者还知道说的是什么。

### 3. 术语与 README 一致

- **库**：用户选中的那个照片目录（README 的定义）。不写「相册库」；「照片文件夹」只用于
  真的在说磁盘目录时（文件对话框、`关于` 里的路径）。
- **当前层级**：网格这一屏代表的东西，不写「这一层」。
- **纯色**：背景不使用图片时的底。挑颜色那个入口叫「设置纯色背景…」（ADR 0101 改的名）。
- **事件**、**相册**、**影片**：不混用「分组」（那是网格的分组形态）。

### 4. 一条横幅：结果 + 能否撤销

```
已重命名为「京都.jpg」；未能记录操作日志，⌘Z 不可撤销。
已将 3 项移到废纸篓。⌘Z 可撤销。
```

- 分句用分号，末尾一个句号；不用感叹号。
- **能不能撤销必须写在同一句里**：只有真的进了撤销栈才说「⌘Z 可撤销」。
- 撤销与失败同时发生时，先说做了什么、再说没做成什么。

### 5. 错误信息要能行动

写清对象与下一步：去哪授权、装什么、等到什么时候。

- 「没有读取该文件夹的权限：…。请在「系统设置 → 隐私与安全性 → 文件与文件夹」中授权后重试。」
- 「未安装 exiftool，无法读取「光圈」字段。…安装命令：brew install exiftool」
- 「文件可能尚未下载完成，例如仍在云盘同步，也可能正被其他程序占用。请等待下载完成后再打开。」

**不写**「请稍后再试」以外的空话，也不写「可能被删掉了或设成了私密，用浏览器打开看看吧」。

### 6. 排版：数字与拉丁字母两侧留空格

`已设为 5 GB`、`已在 ImageGlass 中打开`。**但应用名以汉字收尾时不加尾随空格**：
`已在「日历」中打开当前页`（`已在 日历 中` 会读断一口气）。

### 7. 对话框与提示

- 提示行说清「会发生什么」与「不会发生什么」，用陈述句，不用「挑」「弄」「看看」。
- 按钮用动词短语：`使用纯色`、`一并清理这些`、`恢复这一页的默认顺序`。
- 只在真的会让用户失去什么时才用确认框；确认框正文写清默认选项是什么、取消会怎样。

## 后果

- 说「缓存放哪里」的那句欢迎页提示被删掉：ADR 0038 之后开场**不再询问**缓存位置，
  留着它会教用户等一个不会出现的对话框。现在写的是「首次打开会在库内创建 `.gallery` 目录」。
- 背景图那两条横幅各自点名档位，并锁进 `tests/ui/test_backdrop_flow.py`。
- 影片来源的失败原因统一成「站点返回的信息无法解析 / 未收录该视频」，界面层不再为每个
  来源各猜一种说法。
- 文案改动会牵动断言原文的测试 —— 这是好事：它逼着改的人确认「这句新话是不是更准」。
  这一轮 140 来个文件里，绝大部分改动正是测试与代码一起改。
- `docs/` 与 `README.md` 的术语不跟着变：它们本来就用「库」，这次是界面追上来。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 把「没能」统一成「未能」，其余不动 | 语气统一了，但「这一档」「那一列」这类指代仍然离开现场就说不清 |
| 每个横幅只说结果，撤销能力交给撤销标签 | 用户按下 ⌘Z 之前的那一秒才是他最需要知道「这次撤不回」的时候 |
| 把错误原因原样透传（`Permission denied`） | 用户要的是「去哪授权」；英文原因进日志，不进横幅 |
| 为了整齐把「拷贝」也改成「复制」 | 两者是两件事：`拷贝` 进剪贴板，`复制` 在磁盘上造副本（ADR 0017 / 0044） |
